When does your budget month start?

If you are paid on the 25th, choose 25 and your months run from the 25th to the 24th. This changes the Expenses and Income tabs, budgets, safe-to-spend, the month summary and account limits. The yearly Reports tab stays on calendar months.

Back up your data

Downloads everything (expenses, categories, budgets, recurring rules) as one file you can keep anywhere.

Download backup

The app also saves a copy automatically once a day into the backups folder next to server.js (last 14 kept).

Find duplicate entries

Looks for expenses with the same date, title and amount, or the same transaction ID, so you can keep one and delete the rest. Receipts move to the one you keep.

Import expenses from CSV

Works with spreadsheet or bank-statement CSV files (comma separated, first row = column names). Expenses that already exist (same date, title and amount) are skipped.

Encrypted backup

Protects the file with a passphrase (AES-256). Without the passphrase nobody, including you, can open it.

Automatic daily backups

The app saves one copy a day in the backups folder. Turn encryption on to protect those files with a passphrase you choose once (existing copies are encrypted too). It protects backup files that get copied or leaked on their own; the key is kept in your MySQL database so the app can encrypt automatically, so it does not protect against someone with full access to this PC. To restore an encrypted copy, use the restore box below with the passphrase.

Restore from a backup

Receipt files live in the receipts folder and are not inside the backup file. Copy that folder too if you move to another PC.

This replaces all current data with the contents of the file. A safety copy of the current data is saved in the backups folder first.
